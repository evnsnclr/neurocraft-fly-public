# ADR 0000: Research gate before implementation

- Status: accepted
- Date: 2026-08-16

## Context

The system combines scientific data, approximated neural dynamics, cross-language game control, and potentially restricted datasets. Premature implementation could hard-code an unsupported dataset or architecture and encourage inflated claims.

## Decision

Only governance, research, planning, repository, and source-log files may be created before the seven research lanes are complete. Substantive connectome, neural-runtime, protocol, Minecraft, dashboard, or experiment code begins only after a synthesis selects the dataset, development fixture, dynamics, integration, transport, controls, license posture, testing strategy, and compute envelope.

## Consequences

The first commit is an evidence gate. Implementation choices become traceable and replaceable, at the cost of delaying the vertical slice until research is synthesized.
