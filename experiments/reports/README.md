# Experiment reports

This directory is reserved for small, reviewable machine-readable summaries whose inputs are immutable hash-linked trace receipts. Raw recordings, worlds, checkpoints, and large generated artifacts belong under ignored `artifacts/` or `recordings/` paths.

No behavioral result exists at the current repository state. A report may be added only after its complete trial index, fault/exclusion ledger, artifact hashes, analysis code identity, and claim boundary have been verified.
