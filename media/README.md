# Demo footage

Recorded in Minecraft with OBS on September 5, 2026, by Evan Smith.
These files are unchanged copies of the selected compact-HUD exports.

- [Brush preview](brush-demo.gif): 7 seconds, 1280 × 720, 210 frames.
- [Full demo video](neurocraft-demo.mp4): approximately 2 minutes 27 seconds,
  1920 × 1080, H.264 at 30 FPS, without audio.

The GIF preserves all 210 source frames with 3/4-centisecond delay quantization;
the MP4 preserves 30 FPS timing. No generated motion, interpolation or upscaling
was added. Editorial footers name the active condition and control authority.
[Manifest and checksums](manifest.json).

## What is shown

The preview shows an automated brush input followed by the grooming program
under original weights. Neural readouts select and modulate scripted motion.
The longer edit contains the six prepared interactions, weight-shuffle and
no-input comparisons, restored-original brushing, and a separately labeled
operator-selected movement tour. It contains cuts between takes; it is not an
uninterrupted human-played session.

The approach stimulus uses scripted scene preparation; brush/attack inputs use
automated native client dispatch. Realized input histories differ between takes.
Selected comparisons retain responses under shuffling, and baseline cruise can
move the body with sensory input disabled. These single takes illustrate the
implementation rather than establishing biological behavior or a general control
advantage. Earlier failed preparations and stalled capture sections were excluded
from this showcase and retained in the development records. Some wide shots show
a small fly; food obscures parts of the feeding animation.
